Transcriptome analysis of seven tissues in Blue-breasted Quail reared at high and low altitudes

# Blue-breasted Quail RNA-seq Public Release

Versioned public-release packages for the RNA-seq study of blue-breasted quail.

## Download

Download the complete reproducibility package from the
[Releases](../../releases) page.

Each release contains:

- sample metadata and experimental-design information;
- gene-level raw-count and TPM matrices;
- differential-expression, PCA, and enrichment-analysis results;
- R analysis scripts;
- custom OrgDb resources and reference annotation;

## Data availability

Raw sequencing reads are deposited in the NCBI Sequence Read Archive under
BioProject accession `PRJNAxxxxxx`.
